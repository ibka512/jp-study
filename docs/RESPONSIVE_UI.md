# 响应式界面维护

本轮沿用米白、青绿和圆润字体，不修改学习流程、存储格式或数据迁移。

## 布局规则

- 普通窄屏使用底部导航；宽度至少 1000px，或宽度至少 600px、横屏且高度不超过 560px 时使用侧栏。
- 首页从 900px 起分栏，学习页面从 600px 起分栏，设置分类从 720px 起分栏。列宽允许收缩，避免用固定最小宽度挤出屏幕。
- 安全区域由 `viewport-fit=cover` 和 CSS `env()` 统一处理；弹窗与对话区使用动态视口高度。
- 实体键盘提示按 `hover` / `pointer` 能力显示。减少动态效果的偏好仍生效。
- 词库的虚拟列表读取实际 CSS 行高、间距和列数。调整窗口或旋转时，根据旧布局中的词条行恢复位置；单纯高度变化不重置列表。
- 页面切换仅使用方向入场动画，结束后不再重播基础淡入。
