# 钟日界面与动效规则

## 方向

墨绿学习手册。以日常练习为核心，暖白画布、纸白内容、墨绿主操作，赭黄标记学习状态。词卡保留日语衬线大字，中文界面采用简体中文系统字体。AI 用轻量紫色标签识别，发送和确认仍使用统一主操作。

设计取向为保留产品身份的重排。变化程度 5/10、动效强度 3/10、信息密度 6/10、素材依赖 2/10、品牌延续 8/10。界面面向手机近距离阅读与桌面连续学习，优先呈现题目和可操作任务。

## 素材与字体

- 标识使用仓库现有 `logo.png`，桌面导航直接引用原图。
- 中文标题和正文使用 `--font-body`，避免混用日文字形。
- 日语词头使用 `--font-word-ja`，假名和日语例句使用 `--font-jp-sans`。
- 英语词头使用 `--font-word-en`，正文使用界面无衬线字体，数字保留等宽排布。
- 词头与例句的 `lang` 来自词条语言，图标使用现有 Material Symbols，文件随网页与 APK 一同提供，许可证在 `vendor/material-symbols-LICENSE.txt`。来源为 https://github.com/google/material-design-icons 。

## 视觉规则

- 唯一主操作为墨绿底和浅色文字；次操作为纸白底和细边；选中项为浅绿底和墨绿边；危险操作使用红色。
- 主内容文字、辅助文字与禁用状态分级。标题 26–35px，正文 16px，辅助文字 12–14px。
- 以 4px 为间距基数，主要使用 8、12、16、24、32px。
- 控件圆角 12px，卡片 20px，大词卡 24px。胶囊用于小标签。
- 内容卡片以细边界区分，浮层使用投影。取消浮雕阴影和阅读区域上的装饰水印。
- 深色模式沿用墨绿灰层级，英日模式共享视觉身份。

## 布局

- 桌面在宽度至少 1000px、高度大于 560px 时使用带品牌的侧栏。
- 低高度横屏使用紧凑图标侧栏，首页状态与练习并排，学习页题目与选项并排。
- 手机竖屏使用底部四项导航，题目和长选项按内容顺序堆叠。
- 弹窗采用动态视口高度和内部滚动，保留安全区、44px 触控区和键盘焦点。
- 词库虚拟列表继续读取实际 CSS 行高与列数，旋转保持词条附近的阅读位置。

## 动效

动效用于反馈、空间联系与状态说明。高频读题不使用装饰循环动画。

| 交互 | 属性 | 时间 | 曲线 |
| --- | --- | --- | --- |
| 按压 | transform | 120ms | cubic-bezier(0.23, 1, 0.32, 1) |
| 页面进入 | opacity、transform，位移 6px | 180ms | 同上 |
| 词卡翻页 | opacity、transform，位移 8px | 100ms 退出、140ms 进入 | 同上 |
| 抽屉 | transform | 240ms 进入、200ms 退出 | cubic-bezier(0.32, 0.72, 0, 1) |
| 居中弹窗 | opacity、transform，轻缩放 | 180ms | cubic-bezier(0.23, 1, 0.32, 1) |
| 进度详情 | height、opacity | 180ms | 同上 |
| 主题 | opacity | 160ms | linear |

键盘发起的操作即时显示；减少动态效果时不产生位移。页面进入可取消，进度详情支持连续反向切换。拖动沿用现有手势实现。

## 维护

视觉规则集中在 `ui-system.css`。`style.css` 保留功能布局基础。不要另起平行主题。学习数据、存储键、词库和公开调用保持兼容。

## 此次重排的边界

保留现有标识、导航和操作名称、中日英文字体分工、学习流程与所有本地数据。调整页面层级与留白、桌面导航、卡片与控件形态、低高度布局和动效反馈。移除浮雕阴影、阅读水印、持续进度呼吸和长距离 3D 翻页。

横屏编辑采用两列表单与内部滚动，保存和取消保留在浮层底部；词根审核将词头与拆分建议并排，判断按钮保留在屏幕底部。新增页面或状态必须复用同一套语义颜色与控件规则。

本地图标沿用项目原先使用的字体，不增加运行依赖。网页首次加载增加约 410 KB 图标文件，并由 Service Worker 缓存；Android 继续将字体随包提供。没有数据迁移。
