## 动效与交互检查

通过 13 项检查：指针切页、键盘即时切页、连续切页停在最新页面、进度详情连续反转、浮层关闭途中重新打开、Escape 关闭、词条快速翻页显示最新词条、学习翻页、键盘学习翻页、减少动态效果、深色英语配色、键盘退出学习，以及减少动态效果和键盘模式下浮层/抽屉的零时长过渡。

具体检查中，浮层减少动态效果时的计算过渡时间为 `0s`、不透明度为 `1`；键盘打开浮层及抽屉的计算过渡时间均为 `0s`。原有 3D 翻页替换为 100ms 退出与 140ms 进入，连续翻页取消上一次未完成的内容更新。
